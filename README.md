# Blank DG-LAB

**将您的 DG-LAB Coyote 3.0 设备连接到 Minecraft，体验实时、由游戏驱动的触觉反馈。**

Blank DG-LAB 是一款 Minecraft 客户端模组，通过 DG-LAB Coyote 3.0 设备将游戏内事件转化为物理触觉脉冲。感受每一次击中、每一次坠落、每一次死里逃生——通过深度 Create 与 Aeronautics 集成，**感受每一次转向、爬升与引擎轰鸣**。

> **这是一款触觉/生物反馈外设模组。** 不含任何性主题、NSFW 元素或年龄限制内容。所有反馈完全基于游戏内伤害、玩家动作与载具物理。

> 📖 完整文档与高级配置请参阅 [GitHub Wiki](https://github.com/kskongbai/Blank-DG-LAB/wiki/)
> 📦 模组发布页：[CurseForge](https://www.curseforge.com/minecraft/mc-mods/blank-dg-lab)  
> 🔍 您也可以在 PCL / HMCL 等启动器中直接搜索 **Blank DG-LAB** 进行安装。

## ✨ 功能特性

### 🔗 连接

| 功能 | 说明 |
| :--- | :--- |
| 二维码配对 | 内嵌 WebSocket 服务器生成二维码；DG-LAB App 扫码即连 |
| 无需外部后端 | 模组内置 WebSocket 服务器，无需 Node.js 或其他独立服务 |
| 自动端口检测 | 自动查找可用端口，并提供随机化按钮快速更换 |
| 重连支持 | App 断开后自动尝试重连，无需手动操作 |
| IP 输入净化 | 自动识别并处理中文标点与全角数字等手动输入问题 |

| 模组 | 功能 | 说明 |
| :--- | :--- | :--- |
| **Create: Aeronautics** | 速度映射触觉 | 载具速度直接映射振动强度，飞得越快反馈越强 |
| | 转向感 | 转向时根据角速度添加额外脉冲，倾斜与翻滚均可感知 |

## 🚀 快速开始

| 步骤 | 操作 |
| :---: | :--- |
| 1 | 将 `blankdglab-<version>.jar` 放入 `mods` 文件夹 |
| 2 | （可选）一并安装 Create 和/或 Aeronautics 以获得完整载具反馈 |
| 3 | 游戏内按 `B` 键打开主菜单 |
| 4 | 点击“二维码连接”，用 DG-LAB App 扫描二维码 |
| 5 | App 内进入 Socket 控制页，点击 A/B 通道限制的 `+` 按钮设定上限 |
| 6 | 开始游戏，HUD 显示“✓ 已连接”即配置成功 |

## ⚙️ 配置说明

所有设置可通过 `B` → 主菜单 → 设置访问，或直接通过 YACL 图形界面。  
配置文件保存于 `config/blankdglab.json`。

### 连接设置

| 设置 | 说明 | 默认 |
| :--- | :--- | :---: |
| 服务器端口 | 内嵌 WebSocket 服务器端口 | 8877 |
| 手动 IP | 覆盖自动检测的 IP（留空则自动） | - |
| 最大强度 | 游戏端强度上限 | 40 |
| 最小强度 | 脉冲强度下限 | 0 |
| 同步 A/B 通道 | 将合并后的强度发送至两个通道 | true |

### 伤害反馈

每种伤害类型均独立配置以下三项：

| 设置 | 说明 |
| :--- | :--- |
| 启用 | 切换该伤害类型的触觉反馈 |
| 强度 A / B | A/B 通道各自脉冲强度 |
| 脉冲时长 | 脉冲持续时间（毫秒） |

**支持类型**：通用、弹射物、火焰、坠落、持续伤害、魔法、爆炸、溺水、环境、死亡、攻击、破坏方块

### 状态反馈

| 设置 | 说明 | 默认 |
| :--- | :--- | :---: |
| 低生命值反馈 | 生命低于最大值时触发脉冲 | true |
| 低生命值强度 / 10% | 每损失 10% 生命值的强度 | 5 |
| 低生命值脉冲间隔 | 脉冲间隔（毫秒） | 2000 |
| 低饥饿值反馈 | 饥饿低于最大值时触发脉冲 | false |
| 低饥饿值强度 / 10% | 每损失 10% 饥饿值的强度 | 3 |
| 低饥饿值脉冲间隔 | 脉冲间隔（毫秒） | 3000 |

### Aeronautics 反馈

*需安装 Create: Aeronautics 模组*

| 设置 | 说明 | 默认 |
| :--- | :--- | :---: |
| 速度反馈 | 载具速度映射振动强度 | true |
| 转向反馈 | 角速度触发额外脉冲 | true |
| 高度反馈 | 垂直速度控制强度 | true |
| 碰撞反馈 | 撞击时瞬间强脉冲 | true |
| 引擎振动 | RPM 映射持续振动 | true |
| 故障警告 | 引擎损坏时警报脉冲 | true |
| 气球损伤 | 气囊破裂渐隐脉冲 | true |

### HUD 设置

| 设置 | 说明 | 默认 |
| :--- | :--- | :---: |
| 显示 HUD | 切换 HUD 可见性 | true |
| HUD 样式 | BAR / WAVE / PULSE / NUMBER | BAR |

## 📡 工作原理

```
Minecraft → 内嵌 WebSocket 服务器 → DG-LAB App（手机）→ 蓝牙 → Coyote 设备
```

模组内嵌一个实现 DG-LAB SOCKET V4 协议的 WebSocket 服务器。当您扫描二维码时，DG-LAB App 直接连接到模组——无需外部后端或 Node.js 服务器。模组发送结构化的强度与脉冲命令，App 通过蓝牙将它们中继到设备。

对于 Create/Aeronautics 集成，模组实时读取载具物理数据（速度、角速度、高度、RPM），并使用您配置的曲线将它们映射到触觉强度。

## ❓ 常见问题

**问：这个模组在服务器上允许使用吗？**
答：允许。它仅限客户端，不与服务器逻辑交互。无需服务器安装。

**问：会被封号吗？**
答：不会。它不提供任何不公平优势，也不修改服务器数据包。

**问：需要运行独立后端吗？**
答：不需要。模组有自己的内嵌 WebSocket 服务器。只需扫描二维码并连接。

**问：为什么 APP 中 A/B 通道限制是 0？**
答：SOCKET V2 协议未提供设置 APP 端限制的命令。连接后，请进入 APP 的 SOCKET 控制页，手动点击 A 与 B 通道限制的 `+` 按钮，将其设置为您期望的最大值。

**问：可以与其他触觉设备一起使用吗？**
答：目前仅支持通过官方 SOCKET V2 协议连接的 DG-LAB Coyote 3.0。

**问：需要 Create 或 Aeronautics 才能使用吗？**
答：不需要。两者都是**可选的**。没有它们，模组仍提供完整的基于伤害的触觉反馈。飞行功能是额外加分项。

**问：发现 bug / 有建议——在哪里反馈？**
答：请在 GitHub issue 跟踪器中提交。
